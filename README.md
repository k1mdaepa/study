# study

Python과 AI 관련 학습 자료 및 실습 프로젝트를 분야별로 정리한 저장소입니다.

## 폴더 구성

| 분야 | 경로 | 내용 |
|---|---|---|
| 프로그래밍 | `programming/asyncio/` | Python 동기·비동기 프로그래밍 기초 |
| 머신러닝 | `ml/pytorch/` | PyTorch, 텐서, 머신러닝 및 딥러닝 실습 |
| LLM 에이전트 | `llm/agents/langgraph&ai_agent/` | LangGraph 기반 에이전트, 체크포인트, Human-in-the-loop, 심화 가이드 |
| LLM 파인튜닝 | `llm/fine-tuning/` | LLM 파인튜닝 실습 |
| 개발 도구 | `tools/git/` | Git 명령어 실습 |
| 개발 도구 | `tools/claude-code/` | Claude Code 사용법 정리 |

## 설치

저장소 루트에서 공용 의존성을 설치합니다.

```bash
pip install -r requirements.txt
```
