벡터(1d-tensor): 1차원
행렬(Matrix; 2d-tensor): 2차원
텐서(3d-tensor): 3차원

스칼라: 숫자 1개. ex) 1
벡터: 숫자 여러 개. ex) [3, 5, 7] => 1차원 텐서
행렬: 2차원 텐서

2D Tensor
|t| = (Batch size, dim)
행렬에서 행의 크기 = batch size
열의 크기 = dim

---
훈련 데이터 하나의 크기를 256이라고 했을 때,
[3, 1, 2, 5, ...] 이런 숫자들의 나열이 256의 길이로 있다고 상상하면 됌.
즉, 훈련 데이터 하나 = 벡터 하나에 숫자가 256개가 있음.

훈련 데이터의 개수가 3000개라고 한다면, 전체 훈련 데이터 크기는 3000 x 256
이는 행렬이므로 2D-tensor

3000개에서 1개씩 꺼내서 훈련하느 것도 가능하지만, 보통 덩어리로 처리함.
3000개에서 64개씩 꺼내서 처리한다고 한다면, batch size는 64
그렇다면 컴퓨터가 한 번에 처리하는 2D-Tensor의 크기는 (batch size, dim) 이므로 64 x 256
---

3D Tensor - Vision
|t| = (Batch size, width, height)

3D Tensor - NLP
|t| = (Batch size, length, dim)
=> (Batch size, 문장 길이, 단어 벡터의 차원)

---
NLP 분야의 3D 텐서 예제로 이해하기

train_data = [[나는 사과를 좋아해], [나는 바나나를 좋아해], [나는 사과를 싫어해], [나는 바나나를 싫어해]]

이 상태로는 '나는 사과를 좋아해'가 단어가 1개인지 3개인지 이해하지 못함
우선 컴퓨터의 입력으로 사용하기 위해서 단어별로 나눠주어야 함

[['나는', '사과를', '좋아해'], ['나는', '바나나를', '좋아해'], ['나는', '사과를', '싫어해'], ['나는', '바나나를', '싫어해']]

훈련 데이터의 크기 = (4, 3) 2D-Tensor

컴퓨터는 텍스트보다 숫자를 더 잘 처리하므로, 단어를 3차원 벡터로 변환

'나는' = [0.1, 0.2, 0.9]
'사과를' = [0.3, 0.5, 0.1]
'바나나를' = [0.3, 0.5, 0.2]
'좋아해' = [0.7, 0.6, 0.5]
'싫어해' = [0.5, 0.6, 0.7]

훈련 데이터를 재구성하면

[[[0.1, 0.2, 0.9], [0.3, 0.5, 0.1], [0.7, 0.6, 0.5]],
 [[0.1, 0.2, 0.9], [0.3, 0.5, 0.2], [0.7, 0.6, 0.5]],
 [[0.1, 0.2, 0.9], [0.3, 0.5, 0.1], [0.5, 0.6, 0.7]],
 [[0.1, 0.2, 0.9], [0.3, 0.5, 0.2], [0.5, 0.6, 0.7]]]

훈련 데이터의 크기 = (4, 3, 3) 3D-Tensor

batch size를 2로 설정하면

첫번째 배치 #1
[[[0.1, 0.2, 0.9], [0.3, 0.5, 0.1], [0.7, 0.6, 0.5]],
 [[0.1, 0.2, 0.9], [0.3, 0.5, 0.2], [0.7, 0.6, 0.5]]]

두번째 배치 #2
[[[0.1, 0.2, 0.9], [0.3, 0.5, 0.1], [0.5, 0.6, 0.7]],
 [[0.1, 0.2, 0.9], [0.3, 0.5, 0.2], [0.5, 0.6, 0.7]]]

각 배치의 텐서 크기 = (2, 3, 3)
